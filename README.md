# دليل عماد فريج لأدوات الذكاء الاصطناعي

## التحديث
كل التعديلات في ملف `data.js` فقط:
- **إضافة حساب** (يوتيوب/تيك توك/إنستغرام): ضع الرابط داخل `social`.
- **إضافة أداة**: انسخ سطر أداة والصقه وغيّر الاسم والرابط والقسم.
- **إضافة قسم**: أضف سطراً في `CATEGORIES`.
- كل نص له نسخة إنجليزية في الحقل المنتهي بـ `_en` (مثل `note_en`)، واسم القسم الإنجليزي في `en`.
- غيّر `updated` إلى تاريخ اليوم.

## اللغتان
زر ع / EN أعلى الصفحة. رابط النسخة الإنجليزية: https://emadfraij.github.io/?lang=en

## النشر
المستودع اسمه `emadfraij.github.io` ويُنشر تلقائياً على https://emadfraij.github.io
