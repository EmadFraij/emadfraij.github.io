# دليل عماد فريج لأدوات الذكاء الاصطناعي

## التحديث
كل التعديلات في ملف `data.js` فقط:
- **إضافة حساب** (يوتيوب/تيك توك/إنستغرام): ضع الرابط داخل `social`.
- **إضافة أداة**: انسخ سطر أداة والصقه وغيّر الاسم والرابط والقسم.
- **إضافة قسم**: أضف سطراً في `CATEGORIES`.
- غيّر `updated` إلى تاريخ اليوم.
